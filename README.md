# Rocky Linux Lab

Hands-on Linux administration and enterprise infrastructure training using Rocky Linux 9.

## About this project

This repository documents my practical training with Rocky Linux, focusing on system administration, networking, security, services, troubleshooting, automation, and enterprise Linux concepts.

The goal is to build practical skills that are transferable to RHEL-based enterprise environments.

## Lab Environment

* **Operating System:** Rocky Linux 9
* **Administration:** SSH from Windows
* **Network:** Ethernet / NetworkManager
* **Services:** systemd, SSH
* **Version Control:** Git / GitHub
